# APP MISSION

## Project Name
**kr2en-statement — 증권 거래내역서 모듈 (Securities Module)**

별도 신규 서비스가 아닌, 이미 결제 흐름이 붙어 있는 상용 앱 **kr2en-statement** (https://kr2en-statement.vercel.app) 내부에 추가되는 **증권 특화 변환 모듈**입니다.

## Mission Statement
한국 증권사에서 발급한 거래내역서를 업로드하면, 해외 세무 신고·해외 금융기관 계좌 개설·이민/유학 자산 증빙에 바로 제출할 수 있는 **공식 영문 거래내역서로 변환**해주는 기능을 기존 kr2en-statement 앱에 모듈로 추가한다.

## Problem Statement
해외 거주 한국인 투자자와 해외 이주·유학 준비자는 한국 증권사 거래내역서를 영문으로 제출해야 하는 상황(미국 세무 신고, 해외 은행/증권사 계좌 개설, 이민·유학 자산 증빙)에서 직접 번역하거나 번역공증을 의뢰해야 한다. 증권 거래내역서는 일반 은행 거래내역서와 달리 **종목명-티커 매핑, 매수/매도 구분, 평가손익, 양도세·배당, 환전 내역** 등 도메인 특화 항목이 많아 일반 번역으로는 해외 기관이 수용하지 않는 경우가 빈번하다. 기존 kr2en-statement 사용자들로부터 "증권사 거래내역서도 지원해 달라"는 요청이 반복적으로 들어왔다.

## Target Users
- **(1순위 페르소나) 미국 거주 한국인 투자자** — 미국 세무 신고(Form 1040, FBAR, Form 8938 등)에 한국 증권 계좌 내역 첨부
- **해외 이주·유학 준비자** — 비자/영주권 신청 시 자산 증빙
- **해외 금융기관 계좌 개설자** — 신규 증권/은행 계좌 개설 시 기존 투자 이력 증빙
- **세무사·회계사** — 해외 거주 고객의 한국 증권 내역을 영문으로 정리해 제출

## App Type
- [x] 공개/상용 (Public/Commercial) — 기존 kr2en-statement 앱의 모듈로 동작
- [ ] 개인용

기존 앱과 동일한 결제 모델(페이지당 ₩2,000 추정)을 그대로 적용한다.

## Core Features (v1)

사용자 요구사항으로 **증권 거래내역서의 8개 핵심 항목 모두 v1에 포함**한다. 일반적인 "v1 최대 5개 기능" 가이드라인을 의도적으로 확장해, 항목들을 **3개 핵심 기능 묶음**으로 구조화했다.

### 1. 증권사 거래내역서 업로드 및 양식 인식
- PDF/이미지 업로드 (기존 kr2en-statement 업로드 흐름 재사용)
- 한국 주요 증권사 양식 자동 인식 (어떤 증권사 양식인지 식별)
- 페이지 단위 결제 연동 (기존 앱과 동일)

### 2. 증권 거래 항목 추출·번역 (8개 항목 전부)
업로드된 거래내역서에서 다음 항목을 추출하고 영문으로 변환한다:
- **종목명 + 영문명/티커 매핑** — 예: 삼성전자 → Samsung Electronics Co., Ltd. / 005930.KS, 카카오 → Kakao Corp. / 035720.KS
- **매수/매도 구분** — Buy / Sell
- **수량·단가·거래금액** — Quantity / Unit Price / Trade Amount (KRW + USD 환산 옵션)
- **평가금액·평가손익** — Market Value / Unrealized Gain·Loss
- **배당금 내역** — Dividend Income (지급일, 종목, 세전·세후 금액)
- **양도소득세·거래세** — Capital Gains Tax / Transaction Tax
- **입출금(예수금) 내역** — Deposit / Withdrawal (Cash Balance)
- **환전 내역(해외주식)** — Currency Exchange (KRW ↔ USD 등, 환율 포함)

### 3. 공식 제출용 영문 PDF 생성
- 해외 기관이 수용 가능한 표준 포맷(컬럼 정렬, 합계 행, 통화 표기 명확화)으로 영문 PDF 다운로드
- 변환 결과 미리보기 및 항목별 수정(인라인 편집) 가능
- 원본 한글 ↔ 변환 영문 매핑 보기 (검증용)

## Anti-Scope (v1에서 하지 않는 것)

- **별도 도메인/서비스로 분리하지 않음** — 본 모듈은 kr2en-statement 앱 내부 흐름에 통합되며, 신규 브랜드/도메인을 만들지 않는다.
- **실시간 증권사 API 연동 금지** — OAuth/스크래핑/Open API로 계좌 자동 조회는 v1 범위 밖. 사용자가 직접 다운받은 거래내역서를 업로드하는 방식만 지원.
- **세무 신고서 자동 작성 금지** — Form 1040, Schedule D, Form 8938 등 미국 세무 신고서 자체를 생성하지 않는다. 어디까지나 "거래내역서 영문 변환"까지만.
- **암호화폐 거래내역 미지원** — 주식·ETF·채권 등 전통 증권만 v1 대상.
- **번역공증·영사확인 등 법적 인증 서비스 미제공** — 단순 영문 변환 결과만 제공.
- **투자 자문·세무 자문 미제공** — 변환 결과에 대한 해석이나 절세 가이드 제공 안 함.

## Open Questions

다음 항목은 미확정 상태로, 빌드 착수 전 또는 v1 베타 중에 확정 필요:

1. **주 사용처 우선순위** — 현재는 "전부 커버하되 미국 세무 신고용을 1순위 페르소나"로 가정. 실제 사용 데이터·인터뷰로 검증 필요. (이민 증빙용과 해외 계좌 개설용은 포맷 요구사항이 다를 수 있음)

2. **우선 지원 증권사 양식 범위** — 키움·미래에셋·삼성·한국투자·NH투자·KB증권·신한투자 등 중 어디부터 지원할지 미정. v1 출시 시 최소 몇 개 증권사 양식을 커버할지 결정 필요.

3. **성공 지표 수치의 실측 기준선** — 위 표의 가설값(정확도 95%, 매핑 98%, 60초 등)이 적정한지 사용자 확정 필요. 특히 "행 단위 정확도"의 측정 방법론(샘플링/스팟체크/전수검사) 합의 필요.

4. **영문 PDF의 표준 포맷** — 미국 IRS 제출용, 해외 은행 KYC용, 이민국 자산증빙용에서 요구하는 포맷이 미세하게 다를 수 있음. v1에서는 단일 범용 포맷으로 출발할지, 사용처별 템플릿을 제공할지 결정 필요.

5. **기존 kr2en-statement와의 UI 분기 방식** — 업로드 시 "증권사 거래내역서"를 사용자가 직접 선택하게 할지, 양식 자동 감지로 자동 분기할지(또는 양쪽 모두 지원할지) 결정 필요.
