# 🎯 APP MISSION

## Project Name
거래내역서 영문 변환기 (TradeStatement EN)

## Mission Statement
증권회사 지점 직원이 외국인 고객을 위해 한글 거래내역서를 30초 안에 영문 PDF로 변환할 수 있도록 돕는 사내 업무용 도구.

## Problem Statement
증권회사 지점에는 외국인 고객이 본국 세무 신고, 자산 증빙, 송금 사유서 등으로 사용할 영문 거래내역서를 요청하는 일이 자주 발생한다. 현재는 지점 직원이 한글 거래내역서를 받아 종목명·적요(거래 사유)·금액 표기를 손으로 하나씩 영문으로 옮겨 적고 있어, 1건당 약 반나절(4시간)이 걸리고, 직원마다 번역 표현이 달라 회사 차원의 표준화도 어렵다.

## Target Users
- **1차 사용자(앱을 실제 조작하는 사람)**: 증권회사 지점 직원
- **최종 수혜자(결과물을 받는 사람)**: 그 지점의 외국인 고객 (본국 세무·증빙 용도로 영문 거래내역서가 필요한 사람)

## App Type
- [x] Personal/Private Use (사내 업무용 — 일반 대중 공개 X)
- [ ] Public/Commercial

## Core Features (v1)
1. **한글 거래내역 입력 (엑셀 + 이미지)**: 직원이 엑셀 파일을 업로드하거나, HTS 화면 캡처·스캔본 같은 이미지를 올리면 거래 항목(종목/적요/수량/금액 등)을 읽어들인다.
2. **종목명 자동 영문 치환 사전**: 자주 거래되는 종목의 한글 ↔ 영문 매칭을 사전으로 보유하고, 입력된 한글 종목명을 자동으로 영문으로 바꿔준다.
3. **적요(거래 사유) 자동 영문 치환 사전**: "매수", "배당금", "원천징수" 등 거래 적요의 한글 ↔ 영문 매칭을 사전으로 보유하고 자동 치환한다.
4. **신규 항목 AI 자동 번역 + 사전 누적**: 사전에 없는 새 종목명·적요가 들어오면 AI가 영문 번역을 제안해 자동 채워 넣고, 그 결과를 사전에 누적한다. 쓸수록 사전이 두꺼워지고, 회사 표준 영문 표현이 자연스럽게 통일된다.
5. **영문 PDF 출력**: 변환된 영문 거래내역을 외국인 고객에게 그대로 전달할 수 있는 공식 양식의 PDF로 저장·다운로드한다.

## Anti-Scope (What this app will NOT do in v1)
- **국내 주식·ETF 외 상품 미지원**: 파생상품(선물·옵션), 펀드, 채권, 해외주식의 거래내역 전환은 v1에서 다루지 않는다.
- **영어 외 다른 언어 미지원**: 중국어·일본어 등 다국어 출력은 하지 않는다 (영문 단일).
- **사전 수동 편집 UI 미제공**: v1에서는 사용자가 사전을 직접 추가/수정/삭제하는 화면을 제공하지 않는다. (자동 누적만)
- **직원 로그인 / 권한 관리 미구현**: v1에서는 다중 사용자 계정·역할 분리·감사 로그 등을 다루지 않는다.
- **고객에게 직접 전송 기능 미제공**: 이메일·메신저로 PDF를 고객에게 자동 발송하는 기능은 v1 범위 밖이다. (직원이 받아서 직접 전달)
- **원본 거래내역과의 회계 검증/감사 기능 미제공**: 금액 합계가 맞는지 회계적으로 검증하는 책임은 직원에게 있다.

## Success Metrics
| Metric | Target | Timeframe |
|--------|--------|-----------|
| 거래내역서 1건 영문 변환 소요 시간 | 약 4시간 → **30초 이내** | v1 출시 시점 |
| 사전 자동 누적률 (신규 종목·적요가 AI로 채워져 사전에 등록되는 비율) | 90% 이상 | v1 출시 후 1개월 |
| 동일 종목·적요에 대한 영문 표현 일관성 (같은 한글 → 항상 같은 영문) | 100% | v1 출시 시점 |
| 사용 지점 직원 수 | 파일럿 지점 1곳 전원 사용 | v1 출시 후 1개월 |

## Open Questions
- **공식 PDF 양식(레이아웃, 헤더/푸터, 로고, 면책 문구)**: 회사 표준 양식이 이미 있는지, 새로 디자인해야 하는지 확인 필요.
- **이미지 입력의 화질·포맷 범위**: HTS 화면 캡처 PNG만인지, 스캔본 PDF·휴대폰 사진까지 허용할지.
- **AI가 생성한 신규 번역의 검수 책임자**: 자동 누적된 번역이 틀렸을 때 누가 언제 바로잡는지 (v2에서 사전 편집 UI로 이어질 가능성).
- **개인정보·고객 식별정보 처리 정책**: 거래내역에 포함되는 고객 성명·계좌번호 등을 어떻게 다룰지 사내 컴플라이언스 확인 필요.
- **파일럿 지점 선정**: 어느 지점에서 먼저 써볼지.
